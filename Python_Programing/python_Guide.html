Week 1 Theory

Module 1: Language Syntax, Data Types & I/O

1. Memory & Data Types

Python is a dynamic, high-level language. Variables act as reference tags pointing to objects in computer memory, rather than fixed static containers.

Data Type Python Class Description Example
Integer int Whole numbers (positive or negative) without decimals. 42, -10
Float float Real numbers written with a decimal point. 3.14, -0.5
String str Textual sequence wrapped in single or double quotes. "Python"
Boolean bool Truth value representing logic. True, False
Instructor Note: The Type Conversion Rule

The input() function always returns user entry as a string (str). Explicit type casting (e.g., int() or float()) is required prior to arithmetic operations.

Common Student Mistake

Trying to concatenate a string with an integer without casting: "Age: " + 25 causes a TypeError. Teach formatted f-strings (f"Age: {age}") early to avoid this.

module_1_demo.pyPython 3.x
# Output and Formatting
name = "Sara"
birth_year = 2004
current_year = 2026

# Type Casting input from String to Integer
user_age_input = input("Enter your age: ")
age_num = int(user_age_input)

# String Formatting using F-Strings
print(f"Hello {name}, in {current_year} your calculated age is {current_year - birth_year}.")
Week 2 Theory

Module 2: Control Flow & Boolean Logic

1. Conditional Evaluation Flow

Execution flows sequentially top-to-bottom unless altered by conditional structures. Python relies strictly on indentation (4 spaces) to define code blocks instead of curly braces {}.

Operator Meaning Logical Operators
== Is equal to and (Both conditions must be True)
!= Is not equal to or (At least one condition must be True)
> / < Greater / Less than not (Inverts boolean truth value)
Critical Distinction: = vs ==

A single equals sign = is an assignment operator. A double equals sign == is a comparison operator. Confusing these causes syntax errors.

module_2_demo.pyPython 3.x
# Decision Tree Logic
score = float(input("Enter test percentage (0-100): "))

if score >= 90:
    grade = "A"
elif score >= 75:
    grade = "B"
elif score >= 50:
    grade = "C"
else:
    grade = "F"

print(f"Final Evaluation Grade: {grade}")
Week 3 Theory

Module 3: Data Structures & Iteration Mechanics

1. Python Lists (Sequence Types)

Lists are ordered, mutable collections capable of storing heterogeneous data types. Indexes start at 0.

Iteration Types: For vs While

Use a for loop when iterating over a known sequence or range. Use a while loop when repetition depends on a dynamic condition evaluated at runtime.

module_3_demo.pyPython 3.x
# List Operations & Loop Structures
inventory = ["Laptop", "Mouse", "Keyboard"]

# Modifying a List
inventory.append("Monitor")

# Definite Loop (For)
print("Current Hardware List:")
for index, item in enumerate(inventory, start=1):
    print(f"{index}. {item}")

# Indefinite Loop (While)
counter = 3
while counter > 0:
    print(f"Countdown: {counter}")
    counter -= 1
Week 4 Theory

Module 4: Functions & Modular Design

1. Function Anatomy & Scope

Functions isolate computational logic into reusable units. They accept parameters (inputs) and return output values using the return keyword.

Variable Scope Warning

Variables declared inside a function exist only within that local scope. Attempting to access local variables outside the function raises a NameError.

module_4_demo.pyPython 3.x
# Defining Functions with Parameters and Return Values

def calculate_tax(subtotal, tax_rate=0.05):
    """Calculates total price including tax."""
    tax_amount = subtotal * tax_rate
    total = subtotal + tax_amount
    return total

# Invoking the function
bill_amount = 150.00
final_bill = calculate_tax(bill_amount)

print(f"Original Bill: ${bill_amount} | Final Bill (with tax): ${final_bill}")
